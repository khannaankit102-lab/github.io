# Professional Portfolio

A sophisticated, responsive professional portfolio website built with HTML, CSS, and modern web standards. Designed with Deloitte's professional colour scheme and British English.

## Features

- **Responsive Design**: Fully optimised for desktop, tablet, and mobile devices
- **Modern Styling**: Professional Deloitte-inspired colour scheme with smooth animations
- **Multiple Sections**: 
  - Hero section with professional headline
  - Credentials showcase
  - Professional summary
  - Detailed experience timeline
  - Areas of expertise
  - Notable projects
  - Professional capabilities and certifications
- **Accessibility**: Semantic HTML and clean code structure
- **Performance**: Optimised images and minimal dependencies

## Colour Scheme

- **Primary Green**: #004B49 (Deep Deloitte Green)
- **Secondary Green**: #00A499 (Bright Accent Green)
- **Dark Grey**: #2D2D2D
- **Light Grey**: #F5F5F5
- **White**: #FFFFFF

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Customise the content with your information:
   - Update your name and professional headline
   - Replace experience entries with your career history
   - Update skills, certifications, and expertise areas
   - Add your social media links in the footer

## Customisation Guide

### Update Personal Information
Edit the following sections in `index.html`:
- Logo and navigation (navbar section)
- Hero section with your professional title
- Summary section with your bio
- Experience timeline with your career history
- Expertise areas relevant to your background
- Projects section with your notable work
- Skills and certifications

### Modify Colours
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-green: #004B49;
    --secondary-green: #00A499;
    --dark-grey: #2D2D2D;
    --medium-grey: #6F6F6F;
    --light-grey: #F5F5F5;
    --white: #FFFFFF;
}
```

### Add Social Links
Update the footer social links:
```html
<a href="https://linkedin.com/in/yourprofile" class="social-link">LinkedIn</a>
<a href="https://twitter.com/yourhandle" class="social-link">Twitter</a>
<a href="mailto:your.email@example.com" class="social-link">Email</a>
```

## Tips for Best Results

1. **Keep Content Concise**: Use bullet points and brief descriptions
2. **Professional Photos**: Consider adding a professional headshot (can be added to the hero section)
3. **Consistent Formatting**: Maintain consistent date formats and writing style throughout
4. **Update Regularly**: Keep your experience and skills current
5. **Test Responsiveness**: View on multiple devices to ensure quality
